# Фруктовый матч 🍒

Очень простой пример веб-игры «три в ряд» на HTML, CSS и JavaScript.

## Запуск

Скачайте репозиторий и откройте `index.html` в браузере. Установка и сервер не нужны.

## Правила

- Нажмите на фрукт, затем на соседний по горизонтали или вертикали.
- Обмен сработает, если получится ряд из трёх или больше одинаковых фруктов.
- Совпадения исчезают, фрукты падают вниз, сверху появляются новые.
- За каждый собранный фрукт начисляется 10 очков, включая цепочки совпадений.
- Если доступных ходов нет, поле обновляется с сохранением очков.
- Кнопка «Новая игра» сбрасывает очки и создаёт новое поле.

Играть можно мышью, касанием или клавиатурой (Tab и Enter/пробел).

## Файлы

- `index.html` — страница игры.
- `style.css` — оформление и адаптация к экрану телефона.
- `game.js` — вся игровая логика.

Без библиотек, сборки и зависимостей.
